What it is

Application

Open-source LoRaWAN gateway, submitted by ManThink for GONGBANS (Nov 2026). ESP32-S3 (WROOM-1 N8R8) + Semtech SX1302 concentrator with dual SX1250; W5500 Ethernet primary uplink, optional 4G (A7670C, PPP) and Wi-Fi STA failover; Semtech packet forwarder, optional BasicStation; web console + REST API, MQTT remote config. Hardware: EasyEDA Pro project (schematic+PCB) and BOM in repo; firmware PlatformIO/ESP-IDF 5.5. MIT licence. For buildings, environmental monitoring, industrial IoT. Pairs with ThinkLink, ManThink's free self-hosted LoRaWAN network server / IoT platform (Docker, Linux x64, no device limit): https://www.think-link.net/ . Supplier reference price (Nov 2026, GD61 indoor, 8 channels): basic Ethernet/Wi-Fi US$50; 4G+PoE US$70; global 4G+PoE US$87; power kit +US$5. EU band/cellular config per country; MOQ/lead time on request. Product page: https://www.think-link.net/devices/gd6/
