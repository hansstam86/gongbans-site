What it is

Application

Module that drives a mono speaker: I2S audio input, class-D output up to 2.65 W, I2C control, built-in DSP with speaker boost and protection algorithms, adaptive excursion control, 8-48 kHz sample rates, adaptive DC-DC converter, DRC. ATU codename Lady-Kobe_TFA9891; ATU level S (sub-system). Status in the Sep 2016 ATU catalogue: completed Aug 2016. Project code P16-024. Design files are not public: ask WPI ATU.
