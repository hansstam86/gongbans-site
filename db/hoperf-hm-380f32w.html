What it is

Application

Not recommended for new designs (NRND, per HopeRF's folder label). A drop-in wireless serial bridge with low sleep current. Wire it to any MCU UART to get a long-range sub-GHz link with no RF configuration. Type: module; Main IC: Cortex-M0+ SoC with radio; Protocol: GFSK; Frequency: 434 / 868 / 915 MHz; TX power: +20 dBm max (-10 dBm min); Sensitivity: -120 dBm @434 MHz, 0.5-1 kbps; Data rate: 0.3-256 kbps UART; Interface: UART; Supply: 1.8-3.6 V; Current: TX 70 mA @+20 dBm, RX 9 mA, sleep 1.5 uA; Key specs: Cortex-M0+ core; 700 m range at 300 bps; Typical applications: automatic meter reading, home security and building automation, sensor nodes and industrial monitoring, wireless sensor networks. Variants: HM-380F32-433S2, HM-380F32-868S2, HM-380F32-915S2. In HopeRF's GitHub folder: datasheet/user guide. Source: HopeRF Product_Portfolio on GitHub (MIT licence), read 17 Nov 2026.
