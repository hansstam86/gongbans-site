What it is

Application

A very sensitive, wide-band sub-GHz transceiver covering narrowband and 169 MHz M-Bus uses. Fits smart meters and long-range sensors. Type: module; Protocol: (G)FSK, 4(G)FSK, OOK, ASK; Frequency: 142-1050 MHz; TX power: +20 dBm (+27 dBm with external FET); Sensitivity: -126 dBm; Data rate: 0.123 kbps-1 Mbps; Interface: SPI; Supply: 1.8-3.6 V; Current: RX 10/13 mA, shutdown 30 nA, standby 50 nA; Key specs: 146 dB link budget, 64-byte FIFOs, AFC, AGC, antenna diversity; Typical applications: smart metering (802.15.4g, M-Bus), remote control, home security and alarm, telemetry, home automation, garage and gate openers, industrial control, sensor networks. In HopeRF's GitHub folder: datasheet/user guide, photos. Source: HopeRF Product_Portfolio on GitHub (MIT licence), read 17 Nov 2026.
