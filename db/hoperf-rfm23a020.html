What it is

Application

A programmable sub-GHz SoC module with 20 dBm output and good sensitivity. Use it as the radio plus brain of a long-range smart-home, lighting or metering node. Type: module; Main IC: SoC with integrated PA (not named in text); Protocol: OOK, (G)FSK, (G)MSK, OQPSK; Frequency: 868 / 915 MHz; TX power: +20 dBm max; Sensitivity: -118 dBm @868 MHz, 2.4 kbps GFSK (-116 @915); Interface: GPIO, SWD (SoC with programmable cores); Supply: 1.8-3.8 V; Current: TX 77 mA @+20 dBm, RX 5 mA, sleep 1.2 uA; Key specs: 27-pin SoC module with many GPIOs; Typical applications: smart meter, home/building automation and security, industrial automation, street lighting, wireless remote control. Variants: RFM23A020-868S2, RFM23A020-915S2, HM-23A020W (same datasheet in its own folder). In HopeRF's GitHub folder: datasheet/user guide, photos. Source: HopeRF Product_Portfolio on GitHub (MIT licence), read 17 Nov 2026.
