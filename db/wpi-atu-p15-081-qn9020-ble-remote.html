What it is

Application

BLE module that pairs with a phone app: shows module information, distance alarm for an anti-loss tag, buttons to control the paired device. 2.4 GHz BLE with integrated power management, 250 kbps to 2 Mbps data rates, programmable output up to 0 dBm; battery, LED, SWD test port. ATU codename Mars-Avatar; ATU level T (total solution). Status in the Sep 2016 ATU catalogue: completed Mar 2016. Project code P15-081. Design files are not public: ask WPI ATU.
