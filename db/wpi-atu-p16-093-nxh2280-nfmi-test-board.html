What it is

Application

Test board for a near-field magnetic induction (NFMI) audio link: line in/out audio codec, Cortex-M0 MCU, LCD showing handshake and status information, G-sensor, lithium-battery powered. ATU codename Lady-NFMI; ATU level S (sub-system). Status in the Sep 2016 ATU catalogue: 65% (prototyping); preparing parts. Project code P16-093. Design files are not public: ask WPI ATU.
