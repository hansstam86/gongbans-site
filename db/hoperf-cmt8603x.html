What it is

Application

Opto-coupler-compatible isolated gate driver, a drop-in upgrade for optical drivers in inverters and power supplies. Type: chip (IC); Main IC: CMT8603X; Interface: LED-like anode/cathode input; Supply: driver side up to 32-36 V; Package / size: SOW6 7.5x4.68 mm; Key specs: 5.7 kVrms (SOW6); 4 A source / 6 A sink; CMTI 150 kV/us; 75 ns delay; Typical applications: DC-AC solar inverters, motor drivers, UPS and battery chargers, isolated DC-DC and AC-DC supplies. Variants: CMT8603X-WF. Datasheet marked preliminary / v0.x. In HopeRF's GitHub folder: datasheet/user guide, PCB layout, schematic. Source: HopeRF Product_Portfolio on GitHub (MIT licence), read 17 Nov 2026.
