What it is

Application

Low-power BLE 5.2 serial bridge on the CMT4531 chip, with Coded PHY for longer range. Easy Bluetooth add-on for any UART-based product. Type: module; Main IC: CMT4531 BLE 5.2 SoC (Cortex-M0 64 MHz); Protocol: BLE 5.2, Mesh, 1M/2M/Coded PHY; Frequency: 2402-2483.5 MHz; TX power: +6 dBm max; Sensitivity: -94 dBm @1M GFSK; Interface: UART 9600-500000 bps (AT commands); Supply: 1.8-3.6 V; Current: RX 3.8 mA, TX 4.2 mA @0 dBm, deep sleep 1.4 uA; Key specs: 256 KB flash, 48 KB RAM, PCB antenna or optional connector; BQB, FCC/CE/IC/SRRC; Typical applications: BLE data transmission to phones/tablets, Beacons. Variants: HM-BT4531-1. In HopeRF's GitHub folder: datasheet/user guide, 3D STEP model, PCB footprint, photos, CE/FCC certification reports. Source: HopeRF Product_Portfolio on GitHub (MIT licence), read 17 Nov 2026.
