What it is

Application

Apple HomeKit motor-control reference board: the HomeKit framework runs on the EMW3165 Wi-Fi module to drive door and window motors from HomeKit apps over Wi-Fi; motor-driver interface, Arduino interface, OLED, two mode keys. ATU codename OP-Lola; ATU level T (total solution). Status in the Sep 2016 ATU catalogue: completed Aug 2016. Project code P16-049. Design files are not public: ask WPI ATU.
