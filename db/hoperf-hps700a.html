What it is

Application

Wide-range digital pressure sensor, e.g. for tyre-style inflators and air pumps. Type: chip (IC); Main IC: HPS700A; Interface: I2C; Supply: 1.8-3.6 V; Current: <0.1 uA standby; Package / size: 3.8x3.6x1.15 mm; Key specs: 0-1600 kPa; abs accuracy +-2.0 kPa (0-700 kPa); Typical applications: portable air pump, mobile barometer, industrial pressure and temperature monitoring, sports watches, weather station. Variants: HPS700A-ZM. In HopeRF's GitHub folder: datasheet/user guide, demo code. Source: HopeRF Product_Portfolio on GitHub (MIT licence), read 17 Nov 2026.
