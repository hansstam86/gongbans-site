What it is

Application

Small Wi-Fi 4 + BLE module with 18 I/O for connected sensors and appliances. Type: module; Protocol: Wi-Fi 802.11 b/g/n, BLE; Frequency: 2412-2484 MHz (Wi-Fi), 2402-2480 MHz (BLE); TX power: +19/+20 dBm Wi-Fi, +10 dBm BLE max; Sensitivity: -99 dBm (1 Mbps DSSS), -74 dBm MCS7; Interface: UART, HSPI, I2C, I2S, GPIO, PWM; 18 I/O; Supply: 2.7-3.6 V (typ 3.3 V); Package / size: 20.3x15.3x2.6 mm, castellated; Key specs: 2 MB SPI flash, on-board PCB antenna, shielded. In HopeRF's GitHub folder: PCB footprint, datasheet/user guide. Source: HopeRF Product_Portfolio on GitHub (MIT licence), read 17 Nov 2026.
